# סטודיו מסות — בנייה גבוהה | חבילת MVP ל-BASE44

כלי תלת-ממדי שמפרק מגדל לבסיס, גוף וכותרת. אפשר להיכנס לכל גוש ולכל מקטע ולשנות את הפרמטרים שלו, והמודל מתעדכן מיד.

## מה בחבילה

| קובץ | תפקיד | איך משתמשים |
|---|---|---|
| `docs/02_prompts.md` | שישה פרומפטים לפי סדר | שולחים ל-BASE44 אחד אחרי השני |
| `docs/03_ui_spec.md` | גיליון-עזר: שלושת המפלסים, שש הקבוצות והיררכיית הכותרות | קוראים לפני ההתחלה, ומצרפים את הטבלה אם BASE44 סוטה |

| `data/presets.json` | פרויקט ברירת מחדל ו-8 טיפולוגיות | מודבק בפרומפט 3 |

## למה החבילה בנויה כך

- **חיסכון בקרדיטים.** הגאומטריה והמציג כבר כתובים ובדוקים, ולכן BASE44 רק מחבר ממשק ולא ממציא מתמטיקה.
- **נתונים במקום קוד.** כל 53 הפרמטרים (12 ברמת בניין, 38 לכל גוש ו-3 סוגים) נמצאים בקובץ אחד. כדי להוסיף פרמטר מוסיפים שורה, בלי לבנות מסך.
- **דקדוק אחד לכל הגושים.** אותן שש קבוצות משמשות את הבסיס, הגוף והכותרת. מקטע יורש מהגוש ומשנה רק מה שנדרש.

## מה ב-MVP ומה בהמשך

**כלול:** שלושה מפלסי עבודה, שש קבוצות פרמטרים, 8 טיפולוגיות, עד 4 מגדלים עם גשר, מבטים קבועים, נתונים מחושבים, שמירה אוטומטית, ביטול, ייצוא PNG ו-JSON.

**בשלב הבא** (לפי האפיון המלא במסמך הקודם): מנוע הנחיות ועמידה, מצב השוואה, מצב מצגת לוועדה, צל לפי שעה ועונה, בניינים שכנים, ייצוא GLB, חיתוך חוצה ומעטפת מותרת.

## הערות

- BASE44 תומך בהתקנת חבילות npm דרך הצ'אט ([תיעוד](https://docs.base44.com/Building-your-app/NPM-packages)). לא מצאתי אישור מפורש לכך ש-`three` זמין בכל תוכנית. **כדאי לבדוק בפרומפט 1.** אם ההתקנה נכשלת, זה החסם היחיד.
- הערכים המספריים בטיפולוגיות הם נקודות פתיחה לדוגמה, לא נתונים של בניינים אמיתיים.
- השמות "סוג Seagram" ו-"סוג Turning Torso" מתארים טיפוסי מסה בלבד.
